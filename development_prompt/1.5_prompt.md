### 🛠️ Prompt 1.5: "The Core Utilities"

> "Great! Our basic application shell exists. Before we write our Database Models or UI screens, we need to lay down our core utility functions.
>
> 1. Create `app/core/time_utils.py`. This should include functions that standardize timezone-aware UTC datetime fetching, so our entire application stays perfectly synced.
> 
> 2. Create `app/core/batch_logger.py`. This should define a native Python logger system focusing entirely on securely writing output files to the local unmapped `instance/` directory.
>
> 3. These generic core functions must have zero dependency on the Flask Request context or the SQLAlchemy database context."

***

### Why this is the perfect middle step:
Core Utilities (like date formatters, file writers, or math helpers) are the very foundational base of the pyramid. By prompting the AI to build `app/core` immediately after the Folder generation (Prompt 1) but before the Database Models (Prompt 3), you guarantee that when the AI eventually builds the database schemas, it natively imports your standard `time_utils.utc_now()` function rather than trying to inject random `datetime.now()` calls into your SQLAlchemy files!
