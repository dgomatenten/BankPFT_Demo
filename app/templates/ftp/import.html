JSON Schema Reference

JSON may be a single config object or an array of config objects. If a product_code already exists, its configuration is updated in-place.

FieldRequiredNotes
product_codeYesMust be unique; matches dim_product
rate_codeYesMatches interest_rate_code in rate table
termYesPositive integer — tenor number
term_multNoD / M (default) / Y
avg_periodNoInteger, default 1
avg_period_multNoD / M (default) / Y
methodNoMOVING_AVG (only available)
is_activeNotrue (default) / false

Single object example:

{
  "product_code": "LOAN_FIXED",
  "rate_code":    "SWAP_RATE",
  "term": 5,      "term_mult": "Y",
  "avg_period": 3,"avg_period_mult": "M"
}

Array example:

[
  { "product_code": "LOAN_FIXED", ... },
  { "product_code": "DEPOSIT",    ... }
]
