source_dim_json modes:

  • "mode":"all" — include all dimension members
  • "mode":"specific","members":[...] — filter to listed values

output_dim_json / credit_dim_json modes:

  • "mode":"same_as_source" — pass source value to output
  • "mode":"lookup","lookup_column":"..." — read from joined lookup
  • "mode":"fixed","value":"..." — hardcode a member value

Omitting credit_dim_json defaults all credit dimensions to same_as_source.
