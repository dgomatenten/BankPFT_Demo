How to use in batch tasks

Reference any active variable in a batch task's params JSON using curly-brace tokens:

{
  "p_processing_date": "{processing_date}",
  "p_run_by":          "{run_by}",
  "p_as_of_date":      "{as_of_date}"
}

Built-in tokens: {as_of_date} — date entered on the batch run form  ·  {run_by} — username of the person running the batch.
All active operation variables are also available as tokens. For example, {processing_date} resolves to the processing_date variable set here. Note: all engines (Allocation, FTP, Data File) use processing_date as the effective date; {as_of_date} gives the raw form input if you need it separately.
